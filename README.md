# Hi, I'm Nate 👋

I'm a product-focused software engineer building production web, mobile, and cloud applications with React, Flutter, Node.js, and Azure.

I enjoy taking complicated product and engineering problems, figuring out how the pieces fit together, and turning them into maintainable software that actually ships.

## What I work on

- **Mobile products:** Flutter applications for iOS and Android, including production releases, CI/CD, TestFlight, Gradle, and environment configuration
- **Frontend systems:** React, TypeScript, reusable component architecture, API integration, accessibility, and application modernization
- **Backend and APIs:** Node.js, Express, REST APIs, authentication, authorization, OTP / 2FA, session management, and production troubleshooting
- **Cloud infrastructure:** Azure Functions, Blob Storage, Queues, deployment pipelines, logging, and distributed system debugging
- **Product engineering:** Feature ownership from requirements and architecture through implementation, testing, release, and production support
